# ☕ Starbucks Analytics Dashboard

![Dashboard Preview](Starbucks%20Analytics%20Dashboard.png)

## 📌 Project Overview

The **Starbucks Analytics Dashboard** is an interactive Power BI project focused on analyzing the nutritional composition of Starbucks beverages.

This dashboard helps users explore beverage categories, calories, sugars, proteins, caffeine, and fat content through interactive visualizations and KPI metrics. It provides valuable insights into product nutrition and supports data-driven decision-making for health-conscious consumers.

---

## 🎯 Objectives

* Analyze beverage nutritional values
* Compare calories across product categories
* Identify high-calorie drinks
* Explore protein and fat distribution
* Understand Starbucks product composition
* Create an interactive and visually appealing dashboard

---

## 📊 Dashboard Features

### KPI Cards

* ☕ Total Beverages
* 🔥 Average Calories
* 🍬 Average Sugars (g)
* ⚡ Average Caffeine
* 💪 Average Protein (g)

### Interactive Filter

* Beverage Filter

### Visualizations

* Calories by Category
* Product Distribution
* Protein by Category
* Top High-Calorie Drinks
* Total Fat by Category

---

## 📈 Key Insights

* Frappuccino beverages contain the highest average calories.
* Signature Espresso Drinks contribute significantly to protein content.
* A small number of beverages account for a large share of total calories.
* Fat distribution varies considerably across beverage categories.
* Product distribution highlights Starbucks' focus on espresso-based beverages.
