# PhonePe Analytics Dashboard

## Overview
The PhonePe Analytics Dashboard is an interactive Power BI project designed to analyze transaction performance across multiple PhonePe services, including Insurance, Loans, Money Transfer, and Recharge & Bills.

## Tools Used
- Power BI
- Microsoft Excel
- Data Visualization
- Data Analysis

## Key Features
- Interactive KPI Cards
- Transaction Trend Analysis
- Service-wise Performance Analysis
- Payment Success & Failure Analysis
- Loan Analytics Dashboard
- Insurance Analytics Dashboard
- Money Transfer Analytics Dashboard
- Recharge & Bills Analytics Dashboard
- Dynamic Filters and Slicers
